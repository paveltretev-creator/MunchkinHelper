Обзор проекта
=============

Munchkin Helper — это приложение для помощи в настольной игре Манчкин. Оно предоставляет удобный интерфейс для отслеживания игрового прогресса, просмотра справочной информации и управления контентом.

Основные возможности
--------------------

- **Регистрация и авторизация** — создание аккаунтов и безопасный вход
- **Сохранение сессии** — автоматический вход при повторном запуске
- **Игровое состояние** — отслеживание уровня, силы и дебафов
- **Справочник монстров** — просмотр бестиария с фильтрацией по типу
- **Справочник рас и классов** — информация о доступных расах и классах
- **CRUD операции** — создание, изменение и удаление записей через API

Архитектура
-----------

Проект разделён на три основных слоя:

**Backend** — серверная часть на FastAPI с SQLAlchemy для работы с базой данных PostgreSQL. Предоставляет REST API для всех операций.

**Frontend** — клиентское приложение на Kivy с трёхуровневой архитектурой (Screens → Controllers → Services).

**API** — REST-интерфейс между слоями с Pydantic схемами для валидации данных.

Технологии
----------

- **Python 3.11+** — основной язык программирования
- **FastAPI** — веб-фреймворк для API
- **Kivy** — фреймворк для создания GUI
- **PostgreSQL** — реляционная база данных
- **SQLAlchemy 2.0** — ORM для работы с БД
- **Alembic** — система миграций БД
- **Pydantic** — валидация данных
- **Sphinx** — генератор документации
